## &nbsp; &nbsp;About Me

👋 Hi, I'm Soumajit Dutta

I'm a **final-year Computer Science student at KIIT University**, focused on **Machine Learning, Deep Learning, and Data Science**, and currently building my understanding of **Retrieval-Augmented Generation (RAG)** systems.

I also have full-stack development experience, but I gravitate toward the **backend** — data pipelines, model serving, and API design — over frontend work.

- 🧠 Core focus: **Machine Learning, Deep Learning, and Data Science**
- 🌱 &nbsp;Recently started learning **RAG (Retrieval-Augmented Generation)**
- ⚙️ Comfortable across the stack, but **backend-first** in interest
- 🛠️ Building projects like **insight-ml** (AutoML comparison tool), **HireSafe** (ML hiring-risk predictor), and **cosmic-classifier** (planetary habitability classifier)
- 🎯 Preparing for technical interviews at competitive **AI/ML engineering** roles
- 💬 Ask me about **Machine Learning • Deep Learning • RAG • Python • Backend Development**
